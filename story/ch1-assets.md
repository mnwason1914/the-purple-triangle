# 제1장 에셋 목록

**현재 상태 (2026-11-18)**: 1~5번 그림 69개를 Codex CLI(ChatGPT 요금제)로 만들어 넣었습니다. 영상은 구글 플로우로 따로 만들 예정이고, 소리는 지금처럼 코드로 합성합니다.
- 다시 만들기: `art-src/ch1/run.sh [배치]` → 원본이 `art-src/ch1/raw/`에 저장(깃에는 올리지 않음) → `node scripts/art-process.mjs`가 시트를 자르고 배경을 지우고 게임 크기로 줄여 `public/assets/ch1/`와 manifest에 넣습니다.
- 지시문: `art-src/ch1/briefs/` (공통 화풍 `_style.md`, 벽 b1, 바닥·문 b2, 인물 b3, 소품 b4, 얼굴·손 b5). 인물·소품은 한 장에 여러 칸으로 그려 같은 모습을 유지합니다.

아래 이름으로 파일을 만들어 넣으면 그것만 바뀌고, 없는 것은 코드 그림을 씁니다.

## 넣는 방법
1. 파일을 `public/assets/ch1/`에 넣는다. 파일 이름은 표의 이름에 확장자만 붙인다(예: `spr_otto.png`).
2. `public/assets/ch1/manifest.json`에 이름을 적는다.
   ```json
   {
     "images": ["spr_otto.png", "tex_wall_plaster.png"],
     "videos": ["cut_1_intro.mp4"],
     "audio": ["sfx_door_knock.mp3"]
   }
   ```
3. `npm run build` 후 배포.

## 공통 규칙
- **크기는 자유**, **비율만 지킨다**. 손·얼굴·상태창 아이콘은 게임이 자동으로 줄인다. 인물·물건의 게임 속 키는 그림 크기와 상관없이 그대로다.
- **배경**: 벽·바닥·천장은 꽉 찬 그림. 인물·물건·손은 투명 PNG. 투명이 어려우면 **단색 녹색(#00FF00) 배경**으로 만들면 게임이 그 색을 지운다(그림 안에 같은 초록은 쓰지 말 것).
- **방향**: 인물은 정면, 발끝이 그림 아래 끝에 닿게. 물건은 바닥에 놓인 쪽이 아래 끝.
- **화풍**: 16비트 픽셀 아트, 1933년 독일 슐레지엔 시골, 차분한 흙빛. 글자는 넣지 않는다.
- 1배 크기(아래 "기준 크기")는 벽 64×64와 픽셀 밀도가 같다. 더 곱게 하려면 **모든 것을 같은 배수로** 키운다(벽 128×128이면 인물도 2배).
